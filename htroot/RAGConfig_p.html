Wire RAG Retrieval

Tune how YaCy constructs prompts and search queries for Retrieval Augmented Generation.

System Prompt

Style guidance for chats. Scoutro always sends its own base prompt with the security rules first; this text is added below it and cannot change those rules. Keep it concise and friendly.

User Retrieval Prefix

Introduces the numbered search results in RAG mode. The results follow as an untrusted data block with sources [1], [2], ...

Query Generator Prefix

Prompt given to the model that generates search queries from user requests.

Search Document Max Length

Upper bound in characters for all sources of one RAG answer and for the `search` tool result. The actual RAG budget is smaller when the context window (num_ctx in LLM Selection) minus the answer length (max_tokens) does not allow more; sources are never cut in the middle. Default: 30000.

Maximum Sources

Maximum number of numbered sources in one RAG answer (1 to 20). Default: 8.

Source Excerpt Max Length

Maximum characters per source; the passages with the most question terms are taken (400 to 20000). Default: 1500.

Answer Temperature

Sampling temperature of RAG answers (0 to 2) when the client sends none; low values keep answers close to the sources. Default: 0.2.
