Chat tools

Tools are small helper functions the AI may call while it writes an answer, for example to calculate exactly or to read a web page. Whether the chat model can use tools at all is set in LLM Selection.

A tool is used only when it is released for the chat and its maximum calls per answer is above 0. A model with tool support alone releases no tool. The web tools “Query JSON API” and “Fetch web page” reach only public http(s) addresses.

  • Released for the chat the AI may use the tool
  • Not released the release for the chat is missing
  • Deactivated maximum calls per answer is 0

Maximum calls per answer: how often the AI may use this tool while writing one answer. 0 = deactivated.

Date & timeTells the AI the current date and time, optionally for a time zone.What time is it in New York right now?Computed on the Scoutro server; no network access.
Date calculationCalculates with dates: adds or subtracts days, weeks or months, measures the time between two dates, finds the start or end of a period.Which date is 90 days after 1 March 2026?Computed on the Scoutro server; no network access.
CalculatorEvaluates formulas exactly instead of letting the AI estimate the result.What is 17.5 % of 2,340?Computed on the Scoutro server; no network access.
Number wordsTurns written numbers into digits (German, English, French, Spanish, Italian).“einundzwanzig” becomes 21.Computed on the Scoutro server; no network access.
Unit converterConverts length, weight, temperature, volume and speed.How many kilometres are 26.2 miles?Computed on the Scoutro server; no network access.
Query JSON APIReads data from a public web interface (API) that answers in JSON.Ask the public API of a weather service for the forecast for Berlin.Only GET requests to public http(s) addresses; private and internal addresses are blocked, responses are limited to 2 MB. The AI chooses the address itself: release this tool only if the chat may reach the internet.
Table operationsFilters, sorts, groups and counts table rows the AI already has, for example search hits.Sort the hits by city and count them per city.Computed on the Scoutro server; no network access.
Show planShows a step list in the chat while the AI works on a task with several steps.Plan the steps to compare three providers.Only changes the display in the chat; no network access.
Chat helpExplains what the chat can do and why it works the way it does.What can you do?Answers with fixed texts; no network access.
Small talkAnswers greetings and test messages in a friendly way and names what the chat can do.Hello, are you there?Answers with fixed texts; no network access.
Create diagramTurns a description into a Mermaid diagram, for example a flowchart or a sequence.Draw the way from a crawl to the index as a flowchart.Computed on the Scoutro server; no network access.
Diagram as textDraws a Mermaid diagram as text graphics that every chat window can show.Show this flowchart as text.Computed on the Scoutro server; no network access.
Index searchLets the AI run additional searches of its own while answering, besides the automatic search for the question.Also look up the opening hours of these places.Reads search results from your index, or from the YaCy network when global search is switched on; it starts no crawl. It does not use the collection chosen in the chat.
Wikipedia linkBuilds the address of a Wikipedia article from a topic. Together with “Fetch web page” the AI can then read the article.Topic “Kurzzeitpflege” becomes https://de.wikipedia.org/wiki/Kurzzeitpflege.Only builds an address and loads nothing itself.
Fetch web pageLoads a public web page live from the internet and gives the AI its text (up to about 12,000 characters).Read https://example.org/about and summarize it.Only public http(s) addresses; private and internal addresses are blocked. The page is loaded from the internet, not from the index: release this tool only if the chat may reach the internet.
